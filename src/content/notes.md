# Content extraction notes (tanches.gg-site → v3)

These notes come from the read-only source `tanches.gg-site/`. The content JSON files sit next to this file:

- `site.json`
- `pages/*.json` (14 pages)
- `projects.json` (12 case studies)
- `forms.json`
- `assets-used.json`

Copy in those files is verbatim. When a value is computed at runtime, its JS expression is recorded under `_source`. Data that is defined in a page or component script but never rendered is kept under `unrenderedData` in the matching page JSON.

## 1. Placeholders and missing content

  - It is hidden at runtime, because `hasQuote` requires `!r.loading && !/^placeholder/i.test(r.quote.text)`.
  - It still needs the real quote, Jeremy's surname and his job title.
  - In `projects.json` it is flagged `placeholder: true`.
- **8 of the 12 case studies are "loading" stubs.** These are longview, pleasantgrove, fortbend, uh, uhsl, ust, navarro and samsat.

  - The 7 stubs generated by the `forEach` also use `lede: 'Project delivered.'`, so that phrase appears twice on each of those pages.

## 3. Broken or suspicious references

- **No missing asset files.** `assets-used.json` checks every referenced path against the source folder: 179 paths exist and 0 are missing. External URLs are listed separately.
- **The PDF report links to `https://www.tanches.gg/contact`** (www and lowercase).
  - The canonical URL is `https://tanches.gg/Contact`.
  - www → apex has a 301 redirect, but `_redirects` has no rule for lowercase `/contact`, which may 404 on Netlify.
- **The PDF logo always uses the fallback.** The Assessment PDF looks for `img.tg-lion`, and none exists because the Logo component renders a CSS mask or span. So it always uses `assets/logo-mark.png`.
- **Unlabelled form fields.** On the Contact, League and ProjectCTA forms the selects and the textarea have no `name` attribute. The JS collects them by label text, so they only reach Netlify inside the `details` text. They would be lost on a no-JS submission.
- **Contact query parameters.** "Need a lab first?" (League) links to `/Contact?topic=Full%20facility%20build&program=…`, and Contact supports `?name= ?email= ?org= ?program= ?topic= ?tier=`.
  - `PAGE_PREFILL` in Contact.html keys off the current path, which is always "Contact", so its per-page defaults never apply. It looks copied from ProjectCTA.
  - Contact shows a "Report attached" chip when it arrives from Assessment with `?tier=`, but no PDF is attached to the contact submission. The PDF goes with the separate assessment lead.
- **External member portal.** "Member Login" (mobile nav and League hero) points to `https://tel.rally.gg/`, and the League FAQ side link points to `https://tel.rally.gg` (no trailing slash).
- **DEPLOY.md mentions files that are not in the folder:** `.htaccess` (for Apache hosts), `tools/build-site.js` and `tools/analytics.json` (also referenced in a SiteNav comment).
- **`favicon.ico` is unlinked.** It exists at the root, but no page links it; pages use `/assets/favicon-32.png`, `/assets/favicon.png` and `/assets/apple-touch-icon.png`.
- **Brand kit ZIP may be stale:**
  - The SVGs inside it differ in size from the loose SVGs on the site (for example lockup-color-dark is 12,828 bytes vs 21,109 bytes).
  - The ZIP README lists 5 colours (Flame, Rose, Magenta, Violet, Base), while brand.html shows 6 hues (it adds Ember #EE3C37 and Fuchsia #D031B2).

## 5. Tracking, analytics, privacy

- **What `tracking.js` loads.** It is included on every public page as `/tracking.js` and defines `window.TG_TRACKING = { ga4: '', linkedinPartnerId: '', linkedinLeadConversionId: '', metaPixelId: '' }`. **All IDs are empty, so nothing loads.** When an ID is set, it would load:
  - GA4: `https://www.googletagmanager.com/gtag/js?id=<ID>`, plus `gtag('config', ID)`
  - LinkedIn Insight: `https://snap.licdn.com/li.lms-analytics/insight.min.js`. `linkedinLeadConversionId` sets `window.TG_LI_LEAD`.
  - Meta Pixel: `https://connect.facebook.net/en_US/fbevents.js`, plus `fbq('init')` and `fbq('track','PageView')`
- **Lead events.** After a successful form send, `window.tgTrackLead(form)` (in SiteNav) fires `gtag('event','generate_lead',{form_name})`, `fbq('track','Lead',{content_name})` and `lintrk('track',{conversion_id: TG_LI_LEAD})`. Each fires only if that tracker is loaded.
- **Analytics IDs:** none are configured; all are empty strings.
- **Assessment sends a partial lead.** Once name and email are entered, it sends an "Assessment NOT completed" lead on `pagehide` (via sendBeacon) or after 10 minutes idle. This is privacy-relevant; decide whether to keep it in v3.
- **Forms backend:** all forms post to Netlify Forms via `fetch('/')`.
  - The registry is `forms.html` (noindex): contact, league, project-cta, assessment (multipart, with a `report` PDF file), and store-order (shop, out of scope).
  - The honeypot field is `bot-field`.
  - If a send fails, a toast offers a pre-filled `mailto:contact@tanches.gg`.
- **Third-party scripts:**
  - jsPDF 2.5.1 from cdnjs (Assessment only)
  - Google Fonts (Sora, JetBrains Mono) via the design-system `tokens/fonts.css`
  - fontsource TTFs from jsDelivr (`@latest`), used by the Assessment PDF
- **Theme.** The default is light, stored in localStorage key `tg-theme-v2` and set by an inline head script before paint.

## 6. Robots, sitemap, redirects, headers

- **`robots.txt`:** `User-agent: *`, `Allow: /`, `Disallow: /*.dc.html$`, `Sitemap: https://tanches.gg/sitemap.xml`.
- **`sitemap.xml`:** 25 URLs, all with lastmod 2026-11-04.
  - Priorities: home 1.0, the 12 main pages 0.8, the 12 Project-* pages 0.6.
  - 404 is excluded, as it should be.
  - URLs are mixed case (`/About`, `/brand`, `/Project-fortbend`); v3 must keep these exact paths or add redirects.
- **404.html:** robots `noindex`, no canonical, no JSON-LD, og:url `https://tanches.gg/404`, and SiteNav has no `active` prop.
- **`_redirects`:**
  - `https://www.tanches.gg/*` → apex (301!).
  - Every old `*.dc.html` URL → its clean path (301).
  - `/Lab%20Tour.dc.html` and `/Lab-Tour` → `/Technology`; `/Brand.dc.html` → `/brand`; `/index.html` and `/TANCHES%20Home.dc.html` → `/`.
  - `/shop*`, `/hub*`, `/internal/*`, `/shop-store.js`, `/DEPLOY.md` and `/netlify.toml` → `/404.html` (404!).
- **`netlify.toml`:**
  - Publish dir `.`, with no build step.
  - Security headers: nosniff, strict-origin-when-cross-origin referrer, X-Frame-Options SAMEORIGIN, and a Permissions-Policy blocking camera, microphone and geolocation.
  - Cache rules: `/assets/*` and `/team/*` 7 days, `/_ds/*` 1 day, `/*.dc.html` no-cache plus `X-Robots-Tag: noindex`, `/prod_site/*` noindex, nofollow.
- **Per-page SEO pattern.** Each page has a unique title ("<Page> | TANCHES.GG"), description, canonical and og/twitter tags.
  - The og image is always `https://tanches.gg/assets/og-logo.png` (1200×1200, alt "TANCHES.GG lion mark"), with twitter card `summary`.
  - Every page has a BreadcrumbList in its JSON-LD, and home adds Organization and WebSite.
- **`mobile.css` is not loaded everywhere.** It is NOT loaded by index, Technology, Procurement, Projects, Contact, Assessment, League, brand or 404. It is loaded by About, Team, Education, Community, Commercial and all case studies.

## 7. Runtime notes for the rebuild

- **Shared components:** pages are `<x-dc>` templates rendered by `support.js`, with shared components imported via `<dc-import>`. The shared components are SiteNav, SiteFooter, ProjectCTA, SolutionPage (Education, Community and Commercial, via `kind`) and CaseStudy (12 pages, via `project`).
- **ProjectCTA placement.** It appears on home, About, Team, Education, Community, Commercial, Technology, Procurement, Projects, League and all case studies. It is not on Contact, Assessment, brand or 404.
- **Logo.** The lion mark is a base64 PNG data URI inside `_ds_bundle.js` (the Logo component). The wordmark is text: "[" "TANCHES" "." "GG" "]". A file version is in `assets/brand-kit/` (see `pages/brand.json`).
- **Fonts.** Sora and JetBrains Mono are stand-ins: the design-system fonts.css notes that the licensed brand font was never supplied.
- **Not covered here.** `.claude/`, `.impeccable/`, `DESIGN.md` and `PRODUCT.md` exist in the source but are design docs, not page content.
